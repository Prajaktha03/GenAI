# GenAI

A repository containing Generative AI projects, hands-on tutorials, Jupyter notebooks, and Q&A bot applications built using Python and modern GenAI frameworks.

## 📌 Features & Applications
Q&A Bot (1_qnabot.py): Interactive question-answering application powered by Large Language Models (LLMs).
Interactive Notebooks (/notebook & basic1.ipynb): Step-by-step Jupyter notebooks demonstrating core concepts, prompt engineering, and model implementations.
Modular Apps (/apps): End-to-end Generative AI applications and scripts.
